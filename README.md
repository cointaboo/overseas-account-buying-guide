## 一、先搞懂账号从哪儿来

海外账号的货源基本只有三种，价格和风险完全不是一回事：

| 货源模式 | 怎么来的 | 优点 | 主要风险 |
| --- | --- | --- | --- |
| **自养号** | 人工或脚本长期在真实环境养出来的号 | 稳定，有正常使用记录，不容易被风控 | 成本高，单价贵 |
| **接码号** | 用接码平台的手机号批量注册 | 便宜、量大、到手快 | 接码平台号段常被各大平台标记，注册后可能很快受限 |
| **回收号** | 从个人手里回收的旧账号 | 有历史、有好友或使用痕迹 | **可能被原主找回**，这是最大的雷 |

**第一件事就是看商家敢不敢说清来源。** 含糊其辞说"一手货源、绝对稳定"却不讲到底怎么来的，基本可以直接跳过。

## 二、七个最常见的坑

### 1. 同号多卖

一个账号卖给多个人，谁先改密码算谁的。典型表现：下单后给你账密，你还没来得及改，就发现密码已经被改过了。

**防范**：选支持"自动发货 + 独立卡密"的商家，一单一号，不是从一个大池子里随手捞。

### 2. 原主找回

回收号，原主通过注册邮箱或手机号把号要回去。你买的时候好好的，一周后突然被踢下线。

**防范**：到手立刻换绑邮箱和手机号（见第五节）。

### 3. 保号期缩水

嘴上说"保 7 天"，真出问题了就各种理由推脱。

**防范**：下单前把售后条款截图留证；优先选把售后标准**明确写在页面上**的商家。

### 4. 收款不发货

最恶劣的一种。常见于只在聊天群里交易、没有任何自助系统的"商家"。

**防范**：优先选**有独立站点、下单即自动发货**的。人工发货的，对方一旦不回复你就没办法了。

### 5. 没有售后 / 直接跑路

**防范**：看这个商家存在多久了。域名注册不到一个月的"新店"，风险天然更高。

### 6. 低价引流，事后加价

用明显低于市场价的商品把你吸引过去，付款后再告诉你"这个价只能拿这种质量""要好的得补差价"。

**防范**：价格明显偏离行情的时候，先想想便宜从哪来。

### 7. 地区锁与实名要求

有些账号平台本身要求实名或限制地区。买之前先确认你要用的功能在目标地区是开放的，不然买到手也用不了。

## 三、怎么判断一家店靠不靠谱

按重要性排，看这五件事：

1. **发货方式**：有没有自助下单系统？付款后是**自动发卡**还是要等人工？自动发货的可靠性高一个量级。
2. **售后标准是否透明**：几天内包换、什么情况换、怎么申请，写得越清楚越靠谱。
3. **有没有公开的教程和常见问题**：愿意花篇幅教你怎么用的商家，通常也更在意长期口碑。
4. **支付方式**：是否提供多种支付渠道，是否有订单记录可查。
5. **站点本身是否规范**：HTTPS、页面完整、商品分类清楚、库存状态真实。一个连商品描述都糊成一团的站，售后也别指望。

## 四、支付方式：卡密和直充的区别

- **卡密（自助卡密）**：你付完钱，系统直接把账号密码发给你。优点是快、可自助、有据可查；缺点是遇到问题只能走售后流程。
- **直充 / 代充**：商家帮你把服务充到你自己的账号上。优点是省事；缺点是需要把账号信息交给对方，且到账时间依赖对方。

**通用原则**：无论哪种，都要**保留订单凭证**（订单号、时间、聊天记录）。真出问题时，这是你唯一的凭据。

## 五、拿到账号后，立刻做这三件事

这一步比挑选商家还重要——**很多号不是买来就坏的，是买家没做防护才丢的**。

1. **改密码**：用没在别处用过的强密码。
2. **换绑**：把注册邮箱改成自己的邮箱，有手机号的换成自己能收到的号码。
3. **开两步验证（2FA）**：Telegram、推特、苹果 ID 全部打开。做完这三步，原主找回的成功率会大幅下降。

> 补充：苹果 ID 类账号建议额外检查**是否绑定了双重认证**和**是否有未知设备登录**；Telegram 号建议在「设置 → 隐私与安全 → 已登录设备」里踢掉所有陌生设备。

## 六、常见问题

**Q：为什么同一类账号，价格能差好几倍？**
A：货源不同（自养号 vs 接码号）、有没有历史记录、保号期长短、是否含售后，都会显著影响成本。异常便宜的，通常是在某处省掉了成本——那部分风险最终会转移到你身上。

**Q：自动发货和人工发货，差别真的大吗？**
A：大。自动发货意味着你有订单凭证、有稳定交付路径；人工发货把交付质量绑定在"对方此刻是否在线"上，且事后难以追责。

**Q：账号被限制 / 登不上，算商家的问题吗？**
A：要看原因。如果是**收到就是坏的或短期内失效**，属于商家责任，按售后条款走；如果是你使用中触发了平台风控（异地登录、群发、异常操作），那属于使用问题。所以下单前一定要看清售后条款覆盖什么。

**Q：怎么避免买到被原主找回的号？**
A：优先选明确标注货源、支持售后的商家，并且到手后**当天**就完成改密、换绑、开 2FA 三步。
